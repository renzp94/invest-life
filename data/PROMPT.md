# 用 AI 收集行情数据

把下面这段提示词整段复制给你的 AI（ChatGPT / Claude / DeepSeek / 豆包等），把方括号里的内容改成你要的标的，它就会按《投资人生》的格式返回一份 JSON。

拿到 JSON 后有两种用法：

1. **临时试玩**：打开游戏 → 选「宽基指数」→ 点右上角「导 入」→ 选中这个 JSON 文件。
2. **永久内置**：把 JSON 内容合并进 `data/indexes.json` 的 `items` 数组，然后运行 `node build.js`。

> 不想翻文件？游戏配置页右上角的「AI」按钮里就是下面这段提示词，点「复制全部」直接粘贴给 AI 即可。

---

## 提示词（直接复制）

````text
你是一名金融数据工程师。请帮我整理下面标的的【日线历史行情】（每个交易日一条），并严格按照我给的 JSON 格式输出。

## 要收集的标的
[在这里写清楚，例如：沪深300（000300）、中证500（000905）、贵州茅台（600519）]

## 时间范围
从该标的的【最早可得交易日】一直到【最近一个已收盘的交易日】。不要只取最近 10 年，有多少给多少。

## 为什么必须是日线
游戏里 K 线可以切「年 / 月 / 周 / 日」四档，四档全部由你给的数据聚合出来。只有日线，周线和日线才是真实波动；如果给月线，游戏只能拿前后两个月收盘价做几何插值，周/日两档看到的是平滑出来的假曲线。

## 输出格式（严格遵守）
```json
{
  "asOf": "2026-09-30",
  "items": [
    {
      "code": "000300",
      "name": "沪深300",
      "short": "沪深300",
      "div": 0.022,
      "market": "A",
      "points": [
        ["2024-01-02", 3435.66, 3420.11, 3445.20, 3402.88],
        ["2024-01-03", 3420.11, 3438.90, 3450.72, 3415.30]
      ]
    }
  ]
}
```

## 各字段要求
- `code`：标的代码，纯字符串，同一份文件内不能重复。指数用 6 位数字（如 "000300"），个股用 6 位数字（如 "600519"），自定义策略可用任意英文短码（如 "MYROE"）。
- `name`：完整名称，中文。
- `short`：显示在按钮上的短名，**不超过 8 个字**。
- `div`：该标的的**年均股息率**，小数表示，0.022 就是 2.2%。指数参考：沪深300 约 0.022、上证50 约 0.028、中证500 约 0.014、创业板指 约 0.007、科创50 约 0.004、恒生指数 约 0.033、恒生科技 约 0.010、标普500 约 0.013、纳指100 约 0.008。个股用近五年平均股息率，不分红的填 0。
- `market`：所属市场，只能是 `"A"`（A 股）、`"HK"`（港股）、`"US"`（美股）三者之一。游戏按这个字段把标的分组显示，并决定播放哪条市场的事件新闻。**可以省略**——省略时游戏按代码猜：6 位数字算 A 股，`HSI`/`HSTECH`/`HSCEI` 算港股，其余算美股。
- `points`：二维数组，每个元素是 `["YYYY-MM-DD", 开盘, 收盘, 最高, 最低]`（共 5 项）。

## points 的硬性规则（最重要）
1. **必须是日频：一交易日一条，日期精确到日，不能给月线、周线、年线。**
2. 日期**严格升序**，最早的交易日排在最前面。**不能重复同一天**。
3. **不要求日期连续。** 周末、法定假日、停牌日自然没有数据，`["2024-01-05", ...]` 后面直接接 `["2024-01-08", ...]` 是**正确**的写法，不要为了"补齐"编造周末的价格。
4. 日期统一写成 `YYYY-MM-DD`，月、日补零（`2024-01-08` 而不是 `2024-1-8`）。
5. 每条的四个价格依次是：**开盘**、**收盘**、**当日最高**、**当日最低**。保留 2 位小数，不要带货币符号或千分位逗号。
6. **最高价必须 ≥ 开盘和收盘，最低价必须 ≤ 开盘和收盘**，否则数据是错的，游戏会拒绝导入。
7. **至少 400 个交易日**（约两年），少于这个数量游戏里跑不起来。
8. 不要放编造的数据、不要插值补缺。某段时间取不到就跳过那一段，保证给出来的每一条都是真实收盘。

> 如果你只能拿到收盘价，也可以只写 `["2024-01-02", 收盘]` 两项。游戏能跑，但 K 线会把「前一天收盘」当成开盘、最高最低取两端，画出的是近似柱体，不是真实振幅。

## 分批发，别一次输出到一半被截断
日线数据量很大，一次要十年二十年几乎必然被截断。请按下面的方式分批给我，每次只输出一个片段：

- **按标的拆**：一个标的一次，先给第一个，我说「继续」再给下一个。
- **按年份拆**：每个标的按 3~5 年一段，从最早的年份开始，按时间顺序一段段往后给。
- 每一段都必须是**完整合法的 JSON**（可以只有一个 `items` 元素、`points` 只含这一段），我自己拼接。
- 每次输出前告诉我这一段的起止日期，方便我核对有没有漏。

## 输出前请自检
- 抽查 3 个相邻日期，确认是升序、没有重复日期。
- 确认没有把某个日期写成 `2024-1-8` 这种不补零的形式。
- 确认每条的最高价 ≥ 开盘/收盘，最低价 ≤ 开盘/收盘。
- 确认最后一个日期不是"今天"这种还没收盘的日子。
- 确认 JSON 能被 `JSON.parse` 解析，没有尾逗号、没有注释。

## 只要结果
请直接输出**纯 JSON**，不要 markdown 代码块标记，不要解释文字。如果标的很多，就一次性输出完整的 `items` 数组。
````

## 数据量：日线到底有多大

一条完整 OHLC 约 48 字节，只有收盘价约 22 字节。所以：

| 标的数 | 5 年日线（约 1220 点） | 10 年日线（约 2430 点） | 全部历史（20 年，约 4860 点） |
|---|---|---|---|
| 1 个 | 约 58 KB | 约 117 KB | 约 233 KB |
| 5 个 | 约 290 KB | 约 585 KB | 约 1.1 MB |

一次让 AI 输出太多必然截断。**超过 3 年就分批**：先要某标的的头 3 年，再要下一段，最后自己拼 `points` 数组。游戏导入时只认「日期升序 + 不重复」，分段拼接不需要任何额外处理。

---

## 月线还能用吗

能。`points` 的日期写成 `YYYY-MM`（如 `"2024-01"`），就是月频数据，引擎会自动识别。

代价是：**周、日两档 K 线只能用前后两个月收盘价做几何插值**，看到的是平滑曲线而不是真实振幅，月末会精确落回真实收盘价。年、月两档不受影响。

所以建议：

- 想要真实周/日 K → 按上面的提示词收日线。
- 只想快速试玩、不在乎周/日细节 → 月线足够，体积小十倍，AI 也不容易截断。

## 常见问题

**AI 给的是复权价还是原始价？**
指数本身没有复权问题；个股请明确要求「前复权」或「不复权」。游戏用价格指数 + `div` 折算全收益，因此个股建议用**不复权收盘价 + 真实股息率**，这样历史涨跌幅才和当年真实盘面一致。

**AI 说找不到那么早的数据怎么办？**
让它只给你能确认的区间，宁短勿断。缺少的交易日会被当作「没有交易」，价格在前一个收盘价上停住，不会失真。

**导入时报「日期没有升序」或「重复出现」？**
说明 AI 把日期排乱了，或者把同一天输出了两次。日频数据不做连续性校验，但**顺序和唯一性必须保证**——这也是分段拼接时最容易出错的地方。

**导入时报「少于 400 个交易日」？**
日频数据至少要两年。可以让 AI 多给几年，或者改用月频（下限 25 个月）。

**同一份文件里能日线和月线混着放吗？**
不能。每个标的自己看第一个日期决定粒度，同一标的内部不能混。

**数据准不准？**
AI 凭记忆生成的历史价格经常有偏差，日线尤其容易在早期年份编造。关键标的最好从行情网站（东方财富、同花顺、新浪财经）导出后自己转格式，AI 只用来做格式转换和校验。
